# 正式辩论体系专项

适用：辩论赛、议会制辩论、议事会发言、需要身份和环节的完整交锋。

---

## 一、三种赛制一览

| 赛制       | 人数                       | 环节                               | 特点                             |
| ---------- | -------------------------- | ---------------------------------- | -------------------------------- |
| 新加坡模式 | 正反各四人                 | 立论、攻辩（质询）、自由辩论、结辩 | 最常见。一辩立框架，四辩升价值   |
| 奥瑞冈制   | 正反各三人                 | 立论、质询、驳论、结辩             | 政策性辩题为主，重证据与举证责任 |
| 议会制     | 政府方与反对方各两人或四人 | 依次发言，可中途起立质询           | 即兴成分高，重临场               |

拿到任务先问清赛制。赛制决定环节时长与发言权规则，写稿长度因此完全不同。

---

## 二、环节目标清单

每个环节只有一个任务。任务混淆是新手最常见的失分点。

| 环节         | 唯一任务                     | 时长参考     | 交付物             | 忌讳                 |
| ------------ | ---------------------------- | ------------ | ------------------ | -------------------- |
| 立论（一辩） | 立框架、抢定义、封死论证义务 | 三分半       | 定义加三条分论     | 举太多例子、临场发挥 |
| 质询 / 攻辩  | 逼对方确认或否认关键命题     | 每轮一分半   | 二到三个闭合二难   | 自己讲，不给对方说话 |
| 驳论（二辩） | 拆对方框架，补我方漏洞       | 三分         | 三处拆解加一处补充 | 只防守不反击         |
| 自由辩论     | 战场收束、事实压制、记账追债 | 各四到五分钟 | 债务表清零         | 重复前面说过的话     |
| 结辩（四辩） | 升维，讲这件事意味着什么     | 四分         | 分歧点加价值升华   | 做成流水账           |

## 三、位置分工

| 位置 | 唯一任务                                   | 常用开场                   | 忌讳                 |
| ---- | ------------------------------------------ | -------------------------- | -------------------- |
| 一辩 | 立框架、抢定义、封死论证义务               | 开宗明义 / 名不正则言不顺  | 举太多例子、临场发挥 |
| 二辩 | 拆对方框架，补我方漏洞                     | 对方辩友犯了三个错误       | 只防守不反击         |
| 三辩 | 战场收束加事实层压制，通常是自由辩论发动机 | 对方同学的问题我会一一解答 | 重复一二辩说过的话   |
| 四辩 | 升维。不重复事实，讲这件事意味着什么       | 今天我们本是对真理的追求   | 把结辩做成流水账     |

关键差异：一辩稿是赛前写定的，四辩稿是场上改出来的。一辩稿是结构，四辩稿是呼吸。

## 四、四套模板

### 模板一：一辩立论稿（三分半，约八百五十字）

```
【开场 15 秒】致敬主席、评委、观众，一句话速过
【第一段落 30 秒】援古语加引入矛盾，今天我们所要探讨的其实是……
【第二段落 45 秒】名不正则言不顺。按《某某》定义：A 是指……B 是指……
                   所以我方今天只需证明〔低义务〕，即可成立
【第三段落 30 秒 ×3】分点：第一……第二……第三……
                   理论、事实、价值各配一个具名案例
【收尾 20 秒】回扣开头的意象，一句诗或一个反问结束
```

### 模板二：二辩驳论稿（三分钟）

```
【0 到 20 秒】对方同学有三个错误，可惜第一个就是致命的：前提错了。
【20 到 90 秒】逐个拆：定义错误 → 逻辑错误 → 例句失效，每个十五到二十秒，够用就停
【90 到 150 秒】归谬三连：按您的逻辑，那么……难道……？
【最后 30 秒】补我方漏洞：请允许我补充一点，我方认为……
```

### 模板三：四辩结辩（四分钟）三段式升降机

```
【下沉 60 秒】今天这场争论为什么会发生，一句话点破双方真正的分歧点
【平推 60 秒】回溯全场：这个时刻你说不是，那个时刻你仍然说不是
【升维 120 秒】今天我们争的不是一个词，而是……以一句引用或意象收束
```

结尾那一段一定不是总结缺点，而是讲清楚这件事对你我意味着什么。升维的六条路径、假升华清单与逐句拆解的范本，见主文件「五、升华」。

### 模板四：自由辩论追问卡（赛前写满五张）

```
卡片编号 / 目标人
问题（不超过二十五字，必须是闭合二难）
对方可能的三种回答：①……②……③……
每种回答下的追打句：①→……②→……③→……
这是第几次提问？场记符号：正字递增
```

## 五、自由辩论五锦囊

**锦囊一：抢占提问权。** 谁提问，谁设战场。可以发言时如果没有问题，就用「请问对方」造一个。

**锦囊二：每回合答半句加反问一句。** 完整回答等于交出主动权。示范：

> 对方辩友谈到家庭暴力。让我们想一想：家庭暴力大多是男人打女人，男人打女人时说什么？我辛辛苦苦赚钱养家，你还不好好伺候我。还是钱呐。

一手接住对方的例子，一手把例子改写成本方证据。不用自己备素材，素材自己送上门。

**锦囊三：闭合二难提问。** 好问题二选一，且两边都通向己方。

> 成功到底是成为英雄的充分条件还是必要条件？请回答。
> 夸父追日、精卫填海都没有成功，请问夸父和精卫是不是英雄？

**锦囊四：债务记账。** 每场准备一张债务表，把三到五个核心问题写在卡片上，每次提问报数。

**锦囊五：用对方的材料反打。** 自由辩论最高级的动作。

> 对方辩友说到篡改历史我就一肚子气。这种不顾事实、掩盖历史的恶，是钱多烧得慌冲昏了头脑，这难道不是钱的过错吗？

## 六、防守三招

1. **承认、限定、反攻**：这一点我们从不否认，但是我们要的是 X 而不是 Y，因此恰恰证明我方。
2. **改判类别**：这不是恶，这是另一类行为，动物性也好、技术手段也好、时代条件所致也好。
3. **反手归因**：您举的恰恰证明我方，因为这在 X 的前提下才会发生。

## 七、罗伯特议事规则要点

议事场景与辩论赛不同：它有主持人、有动议、有表决，目标是形成决议，不是分出胜负。

### 核心原则

- **主持人中立**：主席不参与辩论，不发表意见，只管程序。
- **一事一议**：同一时刻只讨论一个动议。
- **发言权分配**：未获主持人认可不得发言。主持人应优先给尚未发言的一方，并尽量正反交替。
- **每人每次限时**：同一动议下，同一人发言次数与时长受限，通常每人每日对同一议题发言不超过两次。
- **不得人身攻击**：发言必须针对动议或观点，不得指向个人。
- **程序问题优先**：对程序的质疑可以打断发言，且不需附议。

### 发言流程

```
动议（我提议……）→ 附议（我附议）→ 主持人陈述议题 → 辩论（正反交替）
→ 提出修正案（可选）→ 表决 → 宣布结果
```

### 议事场景下的发言模板

**提出动议**

> 我提议〔具体、可执行的一件事〕，理由是〔一条〕。

动议必须具体可执行，不能是「我们应当重视这个问题」这类表态。

**附议**

> 我附议。

附议只表示「这个议题值得讨论」，不表示赞成。

**反对发言**

> 我反对这个动议。它的成立依赖〔前提〕，而〔前提〕在〔具体处〕经不起检验。我建议改为〔替代方案〕。

议事场合的反对比辩论赛更克制：给出替代方案比单纯否决更有价值。

**程序问题**

> 程序问题。我们现在讨论的内容已经超出本动议范围，请主席拉回议题。

**请求信息**

> 请求信息。这个数字是哪一年度、哪个来源的？

### 议事与辩论赛的三点差异

| 维度   | 辩论赛       | 议事会                       |
| ------ | ------------ | ---------------------------- |
| 判定者 | 评委与观众   | 全体表决                     |
| 目标   | 赢下比赛     | 形成可执行决议               |
| 手段   | 灰色手段可用 | 灰色手段有害，会破坏表决基础 |

议事场合下，扣帽子和隐蔽谬误的收益远低于代价。因为最终要的是别人投赞成票，被人识破一次，后面所有发言都会被扣分。

## 八、评委视角

评委通常从五个维度打分。写稿时对着自查。

| 维度 | 看什么                                 | 常见失分                 |
| ---- | -------------------------------------- | ------------------------ |
| 内容 | 定义是否清晰，论据是否具名可核         | 定义含糊，例子泛泛       |
| 逻辑 | 推论是否成立，有没有被抓到谬误         | 偷换概念，因果倒置       |
| 表达 | 节奏、短句、重音、四字格               | 全篇一个语速，无停顿     |
| 风度 | 是否针对观点而非人，是否承认对方有理处 | 抢话、人身攻击、一字不让 |
| 配合 | 全队是否守住同一套框架                 | 四个位置各说各的         |

一条经验：评委记不住你的第三个例子，但一定记得住你有没有正面回答那个被追问了四次的问题。

## 九、赛前准备流程

1. **拆题**：找出关键词，查工具书，定我方定义。
2. **画战场图**：按主文件第二步填满五格。
3. **写论证树**：主张、三条分论、每条配齐论据与担保。
4. **备反例库**：针对每条分论，预想对方最可能的三个反例，各写一句应对。
5. **做债务表**：三到五个闭合二难问题，写成卡片。
6. **写三套稿**：一辩定稿，二辩写拆点，四辩只写骨架和结尾，中段留白。
7. **模拟一轮**：按时间念一遍，超时就删例子，不要删逻辑。

### 荣誉提名一：胡渐彪的三段爆破

> 对方辩友把一当作万的推论方式，能够论证万恶之源吗？在数学上，把一当作万，本身就是一个推断错误；在逻辑上，以一当万、以偏概全，就不能够是一个有效的推论；在内容上，盖着一大半、只看一小部分，就是以偏概全的诡辩。

学它的句式：在 X 上，在 Y 上，在 Z 上。三句话把对方的论证方法判三遍死刑。

### 荣誉提名二：袁丁的三重归谬

> 如果成功了就是英雄，我们可以得出结论：当上了驸马爷的陈世美不可不谓是个英雄；二战初期的希特勒也不可不谓是个英雄；至于南宋的秦桧，更是一个不可多得的一世英雄，他成功地当上了宰相，成功地除掉了岳飞，更是成功地出卖了国家。但是我想请问对方同学，你们真的认为这些人是英雄吗？

三个方向：成功端、失败端、综合端。结构最完整的一次归谬演示。

### 荣誉提名三：周玄毅的湖水意象

> 当心中有了恶念，就像是清澈的湖水里泛起了污秽。这污秽之源，到底是湖水本身呢，还是外部的杂质呢？外在诱惑就是我们人心中的杂质，而金钱作为一般等价物，则是这种种外部诱惑的抽象化身。

用一个意象完成对方很难反驳的核心论证，是把抽象概念装进图画的范本。
