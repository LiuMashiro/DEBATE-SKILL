# 辩术
** DEBATE-SKILL **

一个面向辩论、争论、反驳与说服性写作的 Agent Skill。

---

## 功能

**从需求出发**

区分「求真 / 争胜 / 竞赛」三种场合，分别规定可用手段。求真场合只用硬逻辑，禁用灰色手段；公开对线与辩论赛允许修辞压制与博弈技法。

**先大纲，写初稿，再修改**

画战场图（争点性质、定义权、义务分配、力量对比、攻击预演）→ 搭论证树（主张一条，分论至多三条，各配论点、论据、担保、佐证）→ 填肉：具名案例、可核数字、权威判据 → 初稿 → 修改为终稿。

**技法库**

立论侧：抢字典、切层次、封死义务、收缩战场、设问自答、价值升维。
反驳侧：反驳五步法（锁定靶心 → 判定谬误类型 → 选拆法 → 承认一句换回十句 → 交付收尾），配套八种拆法（拆定义、拆前提、拆推论、拆因果、拆样本、拆类比、拆后果、拆动机）与十五式驳论技法（归谬、破类比、三段爆破、逼两难、记账式追债、借力打力、承认—限定—反攻等），并针对求真型对话、面子型争论、公共舆论场三种场景给出不同写法，附可直接套用的三句话、一段式、长文驳论模板与讽刺刻度盘。

**逻辑谬误全表**

窃取论题、定义与语言、因果与归纳、相关性与诉诸、形式、论证结构，共 50 条。每条给出定义、例子、破解方法。双向可用：写稿时逐项自检，拆稿时用来定位靶心。

**表达与升华**

涵盖开场正名、三点式骨架、对称排比、掉尾句、四字格密度、短句砸点、称谓管理、化用名言；结辩提供从分歧到共识、从个案到普遍、从批判到建设、从对立到共同处境、从概念到画面、交出裁决权六条路径。

**正式辩论体系**

三种赛制、环节目标清单、位置分工、四套环节稿模板（一辩立论、二辩驳论、四辩结辩、自由辩论追问卡）、自由辩论五锦囊、防守三招、罗伯特议事规则、评委视角、赛前准备流程。

**文风**

三级禁用词表、欧化中文排查对照表、常见语病清单、按场合切换专业与易懂的写法。

**资料查证与引用纪律**

定义判据、统计数据、具名案例、权威观点、反例五类需求定向检索；一手来源优先，两个独立来源交叉验证，引文必核原文。引用只承担四项任务之一（权威判据、历史纵深、画面、升华）。

**四层自检**

成稿前依次过逻辑层（定义、分论独立性、反例检验、谬误排查）、表达层（交付物、具名案例、短句砸点、结尾是否假升华）、文风层（禁用词、欧化中文、空排比）、分寸层（模式是否判对、讽刺刻度、有无捏造）。

**按需加载**

主文件只管「怎么写新内容」，反驳与赛制分别下沉到 `references/` 下的专项文件，按场景路由读取，避免一次性占用上下文。

## 使用方法

在对话中直接描述需求即可触发：

```
帮我反驳这句话：「……」
分析这段话的逻辑漏洞
这个观点站得住吗
以「……」为辩题，写正方一辩立论稿
写四辩结辩，三分钟
在群里回击对方的这个说法，别太长
```

**输出形态**：成稿正文为纯文本段落，不带 Markdown 格式，可直接念或粘贴发布。

可以指定攻击性、文风等。

另有一条硬边界：攻击限于论证本身，不扣人格。讽刺强度由刻度盘控制，越过即失分。

需要说明的是，技能允许在争胜与竞赛模式下使用稻草人、假两难、转移举证责任等灰色技法，这是辩论赛与公开对线的性质决定的；用户应自行判断场合是否正当。
