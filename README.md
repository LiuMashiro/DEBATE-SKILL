# 辩术
**DEBATE-SKILL**

一个面向辩论、争论、反驳与说服性写作的 Agent Skill。

---

## 功能

**从需求出发**

区分「求真 / 争胜 / 竞赛」三种场合，分别规定可用手段。求真场合只用硬逻辑，禁用灰色手段；公开对线与辩论赛允许修辞压制与博弈技法。

**先大纲，写初稿，再修改**

画战场图（争点性质、定义权、义务分配、力量对比、攻击预演）→ 搭论证树（主张一条，分论至多三条，各配论点、论据、担保、佐证）→ 填肉：具名案例、可核数字、权威判据 → 初稿 → 修改为终稿。

**技法库**

立论侧：抢字典、切层次、封死义务、收缩战场、设问自答、价值升维。
反驳侧：反驳五步法（锁定靶心 → 判定谬误类型 → 选拆法 → 承认一句换回十句 → 交付收尾），配套八种拆法（拆定义、拆前提、拆推论、拆因果、拆样本、拆类比、拆后果、拆动机）与十五式驳论技法（归谬、破类比、三段爆破、逼两难、记账式追债、借力打力、承认—限定—反攻等），并针对求真型对话、面子型争论、公共舆论场三种场景给出不同写法，附可直接套用的三句话、一段式、长文驳论模板与讽刺刻度盘。

**逻辑谬误全表**

窃取论题、定义与语言、因果与归纳、相关性与诉诸、形式、论证结构，共 50 条。每条给出定义、例子、破解方法。双向可用：写稿时逐项自检，拆稿时用来定位靶心。

**表达与升华**

涵盖开场正名、三点式骨架、对称排比、掉尾句、四字格密度、短句砸点、称谓管理、化用名言；结辩提供从分歧到共识、从个案到普遍、从批判到建设、从对立到共同处境、从概念到画面、交出裁决权六条路径。

**正式辩论体系**

三种赛制、环节目标清单、位置分工、四套环节稿模板（一辩立论、二辩驳论、四辩结辩、自由辩论追问卡）、自由辩论五锦囊、防守三招、罗伯特议事规则、评委视角、赛前准备流程。

**文风**

三级禁用词表、欧化中文排查对照表、常见语病清单、按场合切换专业与易懂的写法。

**资料查证与引用纪律**

定义判据、统计数据、具名案例、权威观点、反例五类需求定向检索；一手来源优先，两个独立来源交叉验证，引文必核原文。引用只承担四项任务之一（权威判据、历史纵深、画面、升华）。

**四层自检**

成稿前依次过逻辑层（定义、分论独立性、反例检验、谬误排查）、表达层（交付物、具名案例、短句砸点、结尾是否假升华）、文风层（禁用词、欧化中文、空排比）、分寸层（模式是否判对、讽刺刻度、有无捏造）。

**按需加载**

主文件只管「怎么写新内容」，反驳与赛制分别下沉到 `references/` 下的专项文件，按场景路由读取，避免一次性占用上下文。

## 使用方法

在对话中直接描述需求即可触发：

```
帮我反驳这句话：「……」
分析这段话的逻辑漏洞
这个观点站得住吗
以「……」为辩题，写正方一辩立论稿
写四辩结辩，三分钟
在群里回击对方的这个说法，别太长
```

**输出形态**：成稿正文为纯文本段落，不带 Markdown 格式，可直接念或粘贴发布。

可以指定攻击性、文风等。

另有一条硬边界：攻击限于论证本身，不扣人格。讽刺强度由刻度盘控制，越过即失分。

需要说明的是，技能允许在争胜与竞赛模式下使用稻草人、假两难、转移举证责任等灰色技法，这是辩论赛与公开对线的性质决定的；用户应自行判断场合是否正当。

## 示例

谢谢主席，各位评委，各位观众。

今天这场争论能打满全场，是因为在座每一个人都见过苦难。我方从不否认，苦难里也许会长出一些东西。我方全场只争一件事：该被赞美的是那颗在石缝里发了芽的种子，还是那块压在它上面的石头。

《现代汉语词典》对苦难的解释只有两个词：痛苦和灾难。这里没有一个是好词。我方今天只想请对方做一件最简单的事：把"苦难值得被歌颂"这句话按词典翻译一遍，再念出来——痛苦和灾难值得被歌颂。这句话，对方自己念得出口吗？

可对方今天的回答始终只有一个。当尘肺病人跪在床上喘那口气的时候，对方说，这是磨炼；当一个母亲在矿井外等了三天三夜的时候，对方仍然说，这是磨炼；当一个孩子因为几百块钱的学费离开学校的时候，对方还是说，这是磨炼。我三次站起来问过同一个问题，它至今悬在这里：如果苦难真能锻造品格，那同样一场苦难落下来，为什么有人挺住了，有人没有？是苦难挑人，还是另有原因。这个问题，正方一次都没有正面回答。

不止这一处。对方全场有三处错位。

第一处是归因错位。对方说司马迁受宫刑后奋发写出了《史记》。可这句话里真正的因果是"尽管"，不是"因为"。司马迁的伟大在于他忍辱二十年写完五十二万字，不在于那场刑罚。汉代受刑的人成百上千，《史记》只有一部；如果苦难是原因，这些数字怎么解释。对方今天还引了孟子，说天将降大任必先苦其心志。可这句话是谁写下的？是已经担了大任的人回头补的自述。天从来没有公布过它的课程表；那些苦了一辈子、没有等来任何大任的人，谁替他们写过这一句。

第二处是样本错位。我们今天在台上听到的，全是从苦难里活着走出来的人讲的故事。二战时统计学家瓦尔德看过返航飞机的弹孔分布，军方要往弹孔多的地方加装甲，他说不对，该加的是弹孔少的地方——因为打中那里的飞机，一架都没有飞回来。今天能为苦难作证的，都是飞回来的飞机。没有飞回来的那些，有的死在矿井里，有的跪在自家的床上，有的连名字都没有留下。他们不会站在任何一间礼堂里说，苦难真好。

第三处，也是最重要的，概念错位。对方说一个民族走过苦难，就该歌颂苦难。各位，被铭记的和被歌颂的，从来不是一回事。屈原写的是"长太息以掩涕兮，哀民生之多艰"，是哀，不是颂。1937年冬天南京城里那三十万同胞，我们世世代代铭记他们，可谁敢说那场屠杀值得歌颂？把铭记换成歌颂，一个字之差，责任就悄悄换了主人。

所以，摒弃对苦难的歌颂，从来不是一个否定的姿态，它是我们走向美好未来的第一步。

第一，只有不歌颂苦难，赞美才回得去该得的人。张海超是河南新密的一名工人，2009年，为了拿到一张职业病诊断证明，他躺上手术台要求开胸验肺。一个人的病要靠剖开自己的胸膛来证明，这不是磨炼，这是伤害。值得被记住的，是他不肯咽下的那一口气，不是那口被粉尘填满的肺。这一场胜利属于从坑里爬上来的人，不属于那个坑。

第二，只有不歌颂苦难，追问才追得到该问的人。当赞美与勋章齐飞，责任共沉默一色，制造苦难的人就顺理成章地脱了身。贫困不是孩子的磨刀石，被透支的身体不是年轻人的修行，它们都是被制造出来的、可以追责、可以修好的东西，不该是被赞美、被供奉的东西。

第三，只有摒弃歌颂苦难，我们才能真正走向未来。1991年，安徽金寨的苏明娟坐在一间漏风的教室里，那双大眼睛被镜头拍了下来。后来她走进了学校，读完了大学。没有人告诉她苦难值得歌颂，只告诉她这种日子不是天注定。二十多年后，现行标准下9899万农村贫困人口全部脱贫，832个贫困县全部摘帽。一个社会对待苦难最体面的方式，不是把它唱成歌，是让它少一点。

今天我们争的其实不是"歌颂"这两个字。我们争的是：我们要走向一个什么样的未来。

我方说的美好未来，不是一句许诺，它有很具体的样子。那个尘肺病人不必跪着喘气，因为他该拿到的那张诊断书，早在他跪下之前就该交到他手上；那个母亲不必在矿井外等上三天三夜，因为那座矿井本就不该塌；那个孩子不必因为几百块钱离开学校，因为有人替他交了。

那样的未来，不是一座用苦难砌成的纪念碑，而是一个苦难越来越少的人间。

黑夜给了我黑色的眼睛，而我却要用它来寻找光明。

谢谢大家。
